# Travel Hub
Билеты → жильё → аренда авто. Нужен Python 3 и reportlab для PDF: `pip install -r requirements.txt`.

1. Получите бесплатный токен на travelpayouts.com и сохраните: `cp .env.example .env`, вставьте токен.
2. `python3 server.py` → http://localhost:8000

- Билеты: реальные цены Aviasales (Travelpayouts API), города — их автодополнение. Дата необязательна: без неё показываются ближайшие рейсы. Цены переводятся в сомы по курсу open.er-api.com.
- Жильё: реальные отели города из OpenStreetMap (без ключа), карта Leaflet.
- Авто: каталог вручную в `data/cars.json` (цены в сомах, фото из Wikimedia Commons в `public/img/cars`), заявки пишутся в `data/bookings.json`.

## Личный кабинет
- Регистрация и вход по email и паролю (кнопка «Войти» в шапке).
- Пароли хранятся только в виде хэша PBKDF2-SHA256 с солью, сессия — HttpOnly-cookie на 30 дней (в файле хранится хэш токена).
- В кабинете: сохранённые поездки (кнопка «Сохранить поездку» в панели «Ваша поездка»), брони авто с отменой, профиль, смена пароля.
- Данные: `data/users.json`, `data/sessions.json`, `data/trips.json`, `data/bookings.json`. Логика — `auth.py`.

## Заказ и PDF-отчёт
- Когда выбраны билет, отель и автомобиль, в панели «Ваша поездка» становится активной кнопка «Оформить заказ».
- Сервер присваивает номер вида `PT-261104-2914`, сам пересчитывает сумму и сохраняет заказ в `data/orders.json`.
- PDF (`/api/orders/<id>/pdf`, модуль `report.py`): номер заказа с QR-кодом, клиент, перелёт, проживание, авто, итог в сомах.
- Заказ пользователя доступен только ему (и виден во вкладке «Заказы» кабинета); заказ гостя — по секретной ссылке.
- Шрифт DejaVu Sans (свободная лицензия) лежит в `fonts/` — нужен для кириллицы в PDF.
